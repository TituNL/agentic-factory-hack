Knucklebones

A tavern wager of bone and brass — fill your columns, break your rival's matches.

How it scores: each column scores the sum of its dice, but matching values in the same column multiply — a pair counts double each (4 → 16), a triple counts triple each (5 → 45). Placing a die that matches your opponent's value in that same column destroys all of theirs there. Game ends the moment either board fills.
